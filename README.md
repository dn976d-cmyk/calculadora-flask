# Calculadora Modularizada (Flask)

**Autor: Daniel da Silveira Barbosa**

Aplicação web com Python + Flask (lógica) e HTML/JavaScript (interface).
Operações: soma, subtração, multiplicação e divisão — cada uma com sua página
e link no menu superior.

## Como executar

```bash
pip install -r requirements.txt
python app.py
```

Acesse http://127.0.0.1:5000/
